# v1.8.2 Build 79 播放与窗口回归修复

## 用户报告
Build 78 真机持续缓冲；窄窗口仍保留横屏布局，恢复全屏后字体/图标缩小；功能图标未对齐；列表入口隐藏，歌曲多列。

## 修复范围
- 缓存初始化退出播放初始化关键路径。HTTP 资源直接进入播放引擎，不等待缓存串行锁。缓存查找与本地租用设超时和可恢复错误。
- 音源 URL 解析只登记缓存标识，不再抢先启动第二条下载。FLAC 从现有完整响应落盘；系统播放器缓存等完整缓冲后再尝试，避免争用起播流量。
- 新曲零位置不对尚未就绪、暂停的 AVPlayerItem 发起并等待 seek(0)，避免串行播放队列被挂起。非零 seek、暂停恢复保留。
- 重复 buffering 事件不再重置停滞截止时间；JS 资源加载失败进入既有错误恢复控制器。
- 窗口尺寸每次有效 layout 同步更新；iPad 宽度不足 700 点或竖向时恢复手机界面。iOS 字体/图标使用稳定逻辑点，窗口变化只改变布局。
- 辅助播放器按钮统一 44 点触控区 / 18 点图标，去掉额外底部偏移。上一首/播放暂停/下一首 30/38/30 点保持。播放列表改为三横线加播放标记。
- iOS 我的列表不再延迟到抽屉打开才渲染。宽窗口常驻左侧，窄窗口常驻顶部可横向滚动；主要导航增加可见底栏。本地音乐使用正常可管理列表，不是无功能标签。
- iOS 收藏、本地及在线歌曲列表单列，行内按歌曲名/歌手/专辑/时长排列，窄窗口省略低优先级列；保留原有点击、长按、多选和更多菜单。

## 验证方式
既有 18 项磁盘/HTTP 缓存行为测试、19 项播放器布局检查、10 项窗口规则检查保留；新增窗口连续缩放、缓存悬挂降级、零位置起播、按钮/列表规则检查。Actions 额外编译 iPad 模拟器版本，使用合成 MP3/FLAC 实测网络播放、暂停恢复、缓存文件播放、非零 seek、切换引擎，并杀进程/关闭本地 HTTP 服务后重启验证离线缓存和播放中清理。

以对应 Actions 实际日志/结果为准，不在此预先声称模拟器通过。实体设备真实音源的唯一根因在缺少日志时不作保证；模拟器播放进度推进也不等同于对实体设备扬声器的听音验收。产物继续为未签名 IPA 与 Xcode Archive。
