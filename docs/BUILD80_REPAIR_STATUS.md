# 1.8.2 Build 80 · 阅读、列表与音量修复

基线：Build 79 / `f37e95c35ced720d3eafea1d4ae59808975f0632`。
本轮问题与实际修改统一记录在根目录 `CHANGELOG.md` 的 Build 80 条目。

## 明确修复的代码路径

- iOS 正文和辅助文字过小、前景色对比不足；字号独立于图标和几何尺寸，语义文字前景对比按背景计算。
- 单行歌曲列表缺少常驻表头；表头与条目共享相同列布局和实际宽度断点，iOS 宽表格不再沿用手机版默认隐藏专辑的设置。
- 歌单详情缺少桌面主导航和横向操作区域，排行榜缺少榜单标题与显式操作。
- 音量滑块非用户操作的挂载/布局数值回调会写入原生音量；修复为拖动期间才写，面板进入时恢复保存值，提供显式恢复100%。关闭的EQ忽略残留频段参数。
- 本地音乐列表在页面每次挂载时重建；改为持久化一次性初始化。未打开过的列表同样执行持久删除；列表写入串行，迟到同步不创建已移除列表。
- 收藏编辑器采用居中、有界宽度网格；只有明确列表类型的面板从左滑入。共享尺寸上限420×600点，并受当前安全区/键盘可用空间限制。

## 验证分层

1. Node 回归：真实磁盘缓存及模拟持久存储中的列表事件、窗口断点、字体/对比度、弹窗尺寸、音量手势；本地源码转译不是全项目类型检查。
2. Actions 全项目 TypeScript 回归比较与原生 Release 编译。
3. Release 模拟器：MP3/FLAC起播、暂停/恢复、切换、本地缓存、结束进程后断网重开。列表/歌曲移除和初始化标记也用实际原生存储跨进程验证。
4. 增益：AVPlayer实际音量属性；FLAC后混音PCM的RMS/峰值，100%/50%/100%音量线性及单位主混音增益。测试探针仅存在模拟器版本。
5. 界面：用合成数据渲染实际生产表格、收藏编辑器、通用列表面板、播放器设置，取回iPad/iPhone截图进行检查。这不是点击全流程或实体设备窗口系统验收。

本文件不预先宣称构建成功；以对应提交的Actions日志、报告及产物为准。播放进度推进不等于已验证声音幅度；模拟器幅度也不等于实体扬声器/蓝牙的主观响度。

音量恢复不会主动改变系统音量。若此前为了弥补音量降低而把系统音量调高，安装后请先降低系统音量再试听，避免突变。
