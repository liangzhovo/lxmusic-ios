## Build87 新增与修复

### 快速连续快捷键调整进度

连续输入即时累计显示，120 ms 内合并目标，同一时刻只执行一个 seek；过期完成结果和旧进度查询不能回写界面。取消原先反复提交旧目标的校正行为，保留真实原生位置读取、有效零秒、切歌 / 停止取消与错误处理。原生位置查询仍使用 3000 ms 门槛。

MP3 / FLAC 均通过原生快捷键 burst：目标序列 `8 → 13 → 8 → 13 → 8 → 13`，最终保持最新目标并继续推进；没有把旧中间目标逐个重新执行。模拟器通过不等于已穷举实体键盘连按频率和音频听感。

### 跟随系统的独立亮 / 暗主题

移植桌面版的独立预设交互，新增“道法自然”双色入口和亮色 / 暗色分组。两组设置独立保存，系统外观改变时应用对应主题，重启后保留。修改非当前预设不干扰显示，固定主题停止跟随；重新自动跟随后清除窗口 override。修复 iOS 系统版本检测导致 Appearance 监听未注册的问题。

## 安装与验证边界

包内没有 `_CodeSignature` 或 `embedded.mobileprovision`；Archive 没有有效 SigningIdentity。需要使用自己的开发者身份和适用的签名 / 安装方式；本次没有上传 TestFlight 或 App Store，没有进行实体设备长时间播放、全量外部音源或所有蓝牙设备验收。

升级前备份歌单和设置，数据保留取决于应用标识、签名与安装方式；不要把卸载当作普通升级步骤。仅使用有权访问的音乐与可信自定义源。本移植不提供音频源或托管歌曲，不保证第三方源持续可用。
